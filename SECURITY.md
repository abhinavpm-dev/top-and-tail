# Security

Please report a vulnerability in Top & Tail privately, not in a public issue: open the [Security tab](https://github.com/abhinavpm-dev/top-and-tail/security) and click **Report a vulnerability**, or email abhinavpm.dev+topandtail@gmail.com.

Once a fix is out in every store, the advisory is published, with credit to you unless you'd rather stay anonymous.

Only the latest version in each store gets fixes, since the stores update the extension automatically.
