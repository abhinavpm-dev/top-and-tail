# Top & Tail for YouTube: support

Top & Tail is a browser extension for Chrome, Firefox and Edge. It skips each YouTube channel's intro and outro, and can set the channel's speed and volume. You set this once per channel, and every new video from it follows.

This repository is where to report problems, ask questions and follow changes. The extension's code isn't here, so there's nothing to fork or send pull requests to.

## Report a problem

1. Open the extension's popup on the tab where the problem happens, and click **Report a problem** at the bottom.
2. Click **Copy details**. The details say which version you have, your browser, and what the extension did on that video. They never say which video or channel it is.
3. [Open an issue](https://github.com/abhinavpm-dev/top-and-tail/issues/new/choose) and paste them in. Add the video's link if you're happy to share it: it's often the quickest way to find the cause.

Issues are public. Please don't post anything you'd rather keep private; email it instead (below).
